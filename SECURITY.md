# Security

library keeps what a team knows and decides who may read which library, so please report security problems privately:
use the repository's private vulnerability reporting (Security > Report a vulnerability) rather than a public issue.
Include the version, the part (registry, filing cabinet, ...), what you did and what happened.

What is open where, and the limits we know of, are listed in [the portability guide](docs/portability.md) and [the scope audit](docs/scope-audit.md).
